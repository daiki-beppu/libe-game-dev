# JOB BRAWL

ブラウザで動く見下ろし型の 2D 対戦ゲーム。職業ごとの技で相手をステージ（円）から落としたら勝ち。

## 遊び方

`index.html` をブラウザで開く（または `python3 -m http.server 8765`）。

| | 移動 | 攻撃 | 必殺 |
|---|---|---|---|
| 1P | WASD | C | V |
| 2P | 矢印 | . | / |

- T: 2P を CPU ⇄ 人間 に切り替え / Esc: 職業選択へ（職業選択中はゲーム選択画面へ）
- 英数入力モードで遊ぶ

## 構成

- `jobs.js` — 職業と技のデータ（バランス調整はここ）
- `game.js` — エンジン・描画・CPU
