# JOB BRAWL

ブラウザで動く見下ろし型の 2D 対戦ゲーム。職業ごとの技で相手をステージ（円）から落としたら勝ち。

## 遊び方

`index.html` をブラウザで開く（または `python3 -m http.server 8765`）。

| | 移動 | 攻撃 | 必殺 |
|---|---|---|---|
| 1P | WASD | C | V |
| 2P | 矢印 | . | / |

- T: 2P を CPU ⇄ 人間 に切り替え / Esc: 職業選択へ（職業選択中はゲーム選択画面へ）
- 英数入力モードで遊ぶ

## 構成

- `jobs.js` — 職業と技のデータ（バランス調整はここ）
- `config.js` — 画面・ステージ・プレイヤーの定数と小道具関数
- `input.js` — キーボード入力と、プレイヤーごとの入力の読み取り
- `match.js` — ゲーム状態と試合の開始・選択画面への復帰
- `cpu.js` — CPU の操作
- `player.js` — プレイヤーの移動と技の進行
- `combat.js` — ふっとばしの計算式・被弾・飛び道具・落下と残機
- `effects.js` — パーティクルなどのエフェクト
- `render.js` — Canvas 描画
- `main.js` — メインループと場面ごとの進行

`index.html` がこの順に読み込む（ビルド不要）。
